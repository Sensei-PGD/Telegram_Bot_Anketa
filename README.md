# Telegram_Bot_Anketa

## 🤖 Бот-анкета «Я оптимист или пессимист?»

**Телеграм-бот, который проводит психологический тест и определяет, кто вы — оптимист, пессимист или балансированный.**

---

## 📖 О программе

**Бот-анкета** — это телеграм-бот на Python, который задаёт 5 вопросов и определяет ваш тип личности на основе ответов. По итогу бот присылает:

- 🖼 **Картинку** с результатом (оптимист / пессимист / балансированный).
- 📊 **Баллы** по каждому типу.
- 📝 **Детальные результаты** по каждому вопросу.
- 💾 **Сохранение** ответов в JSON-файл.

---

## 🎯 Как работает тест

Тест состоит из **5 вопросов**. За каждый ответ начисляется:

- **+1 балл** — если ответ в сторону **оптимизма**.
- **−1 балл** — если ответ в сторону **пессимизма**.

### Итог

| Сравнение | Результат |
|-----------|-----------|
| Оптимист > Пессимист | 😊 **Ты — оптимист!** |
| Оптимист < Пессимист | 😞 **Ты — пессимист!** |
| Оптимист = Пессимист | 😐 **Ты — балансированный** |

---

## ✨ Возможности

- 🎮 **Простой старт** — через команду `/start_test` или ключевые слова.
- 📋 **Меню команд** — `/start`, `/help`, `/info`, `/start_test`.
- 🔘 **Кнопки ответов** — не нужно печатать текст, выбираешь из вариантов.
- 🖼 **Картинки результатов** — визуальная обратная связь.
- 📊 **Детальные результаты** — баллы по каждому вопросу.
- 🔁 **Повторное прохождение** — кнопка «Пройти ещё раз».
- 💾 **Сохранение** — все результаты пишутся в `user_results.json`.

## ⚙️ Установка и запуск

### 1. Получите токен бота

- Откройте Telegram → найдите **@BotFather**.
- Отправьте `/newbot` → придумайте имя и username.
- BotFather выдаст **токен** вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`.

### 2. Скачайте и настройте проект

Скопируйте файлы в отдельную папку:

```text
optimist_bot/
├── bot.py                ← основной файл
├── Optimist.png          ← картинка для оптимистов
├── Pessimist.png         ← картинка для пессимистов
├── Balanced.png          ← картинка для балансированных
└── README.md
```

### 3. Укажите токен
Откройте `bot.py` и замените:

```python
token = "Your Token"
```

на свой:

```python
token = "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
```

### 4. Запустите
```bash
python bot.py
```

Бот запущен. Найдите его в Telegram и напишите /start.

## 🎮 Как пользоваться

### 1. Запустить бота

Найдите своего бота в Telegram → нажмите **Start**.

### 2. Доступные команды

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и список команд |
| `/help` | Справка по командам |
| `/info` | Подробное описание теста |
| `/start_test` | Начать прохождение теста |

### 3. Начать тест можно ещё и словами

Напишите боту: **начать, начинаем, пройдем, начинай, поехали, пошли, давай, начнем, вперед** — и он предложит пройти тест.

### 4. Ответить на вопросы

Бот задаст **5 вопросов**. К каждому — **кнопки с вариантами**. Нажмите нужный.

### 5. Получить результат

После 5-го вопроса бот пришлёт:

- 🖼 Картинку.
- 📊 Баллы.
- 📝 Детальные ответы.

### 6. Пройти снова или выйти

Появятся кнопки:

- 🔄 **Пройти ещё раз**
- 🚪 **Нет, закончить**
- 📋 **Меню команд**

## 📁 Формат сохранения результатов
Все ответы пишутся в user_results.json (по одной записи на строку):

```json
{"chat_id": 123, "answers": {"Ваш любимый вид отдыха?": "Активный отдых", "Что вы предпочитаете говорить?": "Положительные утверждения", ...}}
```

---

## 📝 Особенности
- **Кнопки с ответами** — пользователь может нажать только их.

- **Проверка ответа** — если пользователь вводит текст руками, бот попросит выбрать из вариантов.

- **Регистр ответов да/нет** — программа понимает любой регистр (`Да`, `да`, `ДА`).

- **Картинки обязательны** — `Optimist.png`, `Pessimist.png`, `Balanced.png` должны лежать рядом с `bot.py`.
